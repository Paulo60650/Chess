# Après l'ouverture
Appli d'échecs en français : ouvertures, plans, tactiques, finales, concepts de stratégie.
Installation : ouvrir la page GitHub Pages du dépôt, puis « Ajouter à l'écran d'accueil » (PWA, fonctionne hors ligne).
Développement : voir CLAUDE.md.
Sauvegarde : onglet Progrès, « Télécharger ma sauvegarde » (fichier JSON) et « Restaurer un fichier ». La progression est stockée dans le navigateur : sauvegarde-la de temps en temps.
Hors ligne : après une première ouverture en ligne, l'appli se recharge sans réseau ; Stockfish et Maia se chargent depuis le réseau au premier usage, puis restent en cache.
